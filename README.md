# 🎨 E-Portfolio | พัฒนพล แอมชัยภูมิ (Graphic Design)

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) ของ **นาย พัฒนพล แอมชัยภูมิ** นักเรียนระดับชั้นมัธยมศึกษาปีที่ 6 โรงเรียนธัญญรัตน์ จัดทำขึ้นเพื่อรวบรวมประวัติส่วนตัว แนวคิดด้านการออกแบบ (Statement of Purpose) ผลงานสร้างสรรค์ด้านกราฟิกดีไซน์ และกิจกรรมต่าง ๆ สำหรับเตรียมความพร้อมเข้าศึกษาต่อใน **คณะออกแบบกราฟิกดีไซน์ สาขาวิชาการออกแบบนิเทศศิลป์**

---

## ✨ จุดเด่นของเว็บไซต์ (Features)

* **โครงสร้างครบถ้วน 4 ส่วนหลัก:** ประกอบด้วย หน้าแรก (Home), แนะนำตัว & Statement of Purpose (About), ผลงาน (Portfolio) และกิจกรรม (Activities)
* **การออกแบบที่ทันสมัย (Modern Blue & White Theme):** ใช้โทนสีน้ำเงิน-ขาวที่ดูสุขุม น่าเชื่อถือ และอ่านง่าย พร้อมฟอนต์ **Prompt** ที่รองรับภาษาไทยอย่างสวยงาม
* **Responsive Design:** รองรับการแสดงผลทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
* **Single-File Architecture:** พัฒนาทั้งหมดด้วย HTML5, CSS3 และ Vanilla JavaScript ภายในไฟล์ `index.html` เพียงไฟล์เดียว ไม่ต้องติดตั้งเครื่องมือหรือไลบรารีเพิ่มเติม พร้อมเผยแพร่บน GitHub Pages ได้ทันที

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5** – โครงสร้างหลักของเว็บไซต์
* **CSS3** – การจัดรูปแบบ Flexbox, Grid, ตัวแปรสี (CSS Variables) และ Responsive Media Queries
* **JavaScript** – ควบคุมการทำงานของเมนูนำทางบนอุปกรณ์พกพา
* **Google Fonts (Prompt)** & **Font Awesome 6** – ฟอนต์และไอคอนประกอบเว็บไซต์
